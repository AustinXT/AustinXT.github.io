布局为 `skills/<name>/SKILL.md`，四个方法共用根 `plugin.json`。它们是本地方法文件，尚未安装为当前会话命令。

| 方法 | 负责 | 状态 |
|---|---|---|
| [mb-init](mb-init/SKILL.md) | 方向与项目边界 | 草稿 |
| [mb-research](mb-research/SKILL.md) | 内容来源、参考、技术及 URL 取舍 | 草稿 |

| [mb-evolve](mb-evolve/SKILL.md) | 批量迁移、长期维护与回归护栏 | 草稿 |

编排：**init → research → proto → evolve → research**。各步放行判据在对应技能内，不在本页复制。

先方法后成品；本地规则检查或同谱系初审不等于跨谱系方法放行。跨谱系外发必须另外确认权限、材料范围与入口；不继承上游评审结果。

包身份在 `../plugin.json`，外部扩展登记在 `../42plugin.json`；只在获准安装后登记扩展，不因模板中存在占位就假装已装。
