# 阳志平网站：现网技术栈取舍卡

核查日期：2026-10-09。**当前可确认的首页与随笔页是 Next.js / React 体系，不应称为仍在用 Jekyll 的网站。** 这是公开发布产物取证，不是作者源码仓库或部署账号审计。

## 当前识别结果

| 层 | 技术 | 确定程度与证据 |
|---|---|---|
| 页面框架 | **Next.js 16.0.10，App Router** | 已确认发布包明示：E3 的 `window.next` 版本与 `appDir`；E1–E2 都引用相同核心资源与 RSC payload |
| UI 运行库 | **React / React DOM `19.3.0-canary-52684925-20251110`** | E3–E4 明示发布包版本；不是普通 React 19.3 稳定版 |
| 打包工具 | **Turbopack** | E1 直接引用 E7 runtime；具体构建命令未知 |
| 样式 | **Tailwind CSS，强烈符合 4 系** | E5 的层、属性与主题变量组合匹配官方 v4；精确版本未确认 |
| 图标 | **Lucide React** | E6 的 React 图标实现与 E1 的 SVG 类名双证据；版本未知 |
| 页面生成线索 | **`v0.app` generator 声明** | E1–E2 明示；可支持使用过 v0 或其模板的判断，不能还原完整 AI 开发过程 |
| 边缘代理 / CDN | **Cloudflare** | E1 响应头直接确认；不等于 Cloudflare Pages 源站托管 |

所有 E 编号的 URL、原件路径及哈希见 `sources.md`；有界反证过程见 `../../experiments/exp002-yang-stack/readme.md`。
