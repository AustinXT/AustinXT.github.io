# 决策点：阳志平网站技术栈

日期：2026-10-09。任务是识别参照站现网技术，不是重新选择本项目框架。

## 三条不可妥协

1. **现网与历史分开**：当前 HTML 与实际引用的资源优先于作者多年前的工具文章；至少用首页与随笔页交叉核查。
2. **每层有直接证据**：框架、样式、图标、边缘服务分别识别；版本只报包内明示值，不从文件名猜版本。
3. **不越过观测边界**：前端资源不能证明数据库、内容后台、源站托管商或构建配置；未知明确标未知。

## 不调查

不扫描私有接口、不寻找凭据、不下载整站或克隆仓库；不调查作者私人开发环境；不把参考站代码、文章、视觉资产作为本项目实现输入。

## 停止条件

能回答现网用了什么、历史线索为何不能替代现网、哪些仍不可确认，以及本项目是否需要重新拍板。证据索引见 `sources.md`，答案正本见 `decision.md`。
