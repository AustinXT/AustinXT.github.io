# 002 · 博客首轮取舍卡

> 2026-10-09；负责人已确认方向并授权继续研究，确认正本见 `../../.42cog/intent.md`。本卡是 AI 推荐，不是技术、人审、制作或上线批准。

## 一、决策点：不可妥协与排除项

1. **先保证文章可读、可找**：桌面与手机的首页→文章、按主题找文、回到列表三个任务；不以功能数量或旧主题兼容率决定。
2. **正文唯一且历史诚实**：历史日期、整理日期、原文指针与新增解释分开；不全量搬文，不把历史知识装作当前实践。
3. **维护与链接可核查**：Markdown 单一正文源、构建版本可锁定；旧 URL 有台账与逐条策略，不整站跳首页。

本轮不调查 CMS、账号系统、实时服务、全平台运营、付费主题或全部外链。先比较至多三个静态方案；没有证据支持先做复杂交互，也没有证据支持“旧站 Hugo，因此必须继续 FixIt”。

## 三、如何分析：本轮核查与差距

核查项按“原件身份→元数据→三篇正文→历史→生成路径”限深；官方资料只查正文与 URL 能力，以及静态托管约束。没有派出分身或外发评审，不能称为已完成跨谱系方法评审。

### 内容组织推荐

- **首页**：简短身份说明、近期文章、全部文章入口。身份说明由负责人定标，不从旧个人信息拼装。
- **全部文章**：按历史日期倒序，支持按年浏览；整理日期另展示，不把旧文洗成今日新作。
- **主题**：先用少量可解释的候选主题——学习与写作、认知与分析、技术与实践；只为已选文章赋值，允许调整，不对 68 篇先批量分类。
- **关于**：仅用获准公开的身份信息；本轮不生成正文。
- **搜索**：保留后续需求，不进入单篇原型。原型先验证列表与主题入口；增加第二篇后再检验“继续阅读”，不编造相关文章。

这些是对现有内容分布的组织建议，不是受众画像已成立。参考站的图书栏目、专题名称与视觉设计不直接复用。

| 生死约束 | Hugo | Astro | Jekyll |

**推荐 Hugo＋独立简洁布局，不继承 FixIt 全套配置。** 依据是当前需求以文字、列表、主题与稳定 URL 为主，并非因为旧站已经使用 Hugo。标准样本由人定；不从参考站复制布局。不在研究阶段选付费主题或安装 Hugo，版本在批准实现前按官方兼容性明确锁定；旧 CI 的版本不是新站自动锁定版本。

**技术备选 Astro**：若负责人近期明确要复杂交互、内容 schema 作为核心工作流或统一前端组件，可改选。当前没有这些强需求证据，不能为了“以后可能”先付依赖成本。

**暂不选 Jekyll**：不是不具备能力，而是在本项目的正文、路径和简洁维护需求下没有胜过首选的明确优势；Pages 能发布其他静态生成器，消除了“仓库名决定 Jekyll”的理由。

## 四、旧 URL 策略与候选迁移台账

URL 实验表明三篇均有标题路径和文件名路径；生成物不是线上真相，也可能残留历史构建。先保留路径而非批量造新 slug，避免把标题修改与地址修改绑定。

| 原文（仅相对原件路径） | 本地 sitemap 旧路径 | 其他历史路径候选 | 目标 / 新 URL 候选 | 取舍 / 时效 / 人审 |
|---|---|---|---|---|
| `content/posts/2019-12-23-卡片学习心得.md` | `/卡片大法/` | `/2019-12-23-卡片学习心得/` | 原生 `content/posts/` 下一份独立整理稿；建议仍 `/卡片大法/` | 首选；2019 历史笔记，部分断言待核；未整理、未人审、未获制作或发布许可 |
| `content/posts/2019-08-04-解读统计数字四步骤.md` | `/解读统计数字的行动清单/` | `/2019-08-04-解读统计数字四步骤/` | 备选，建议仍 `/解读统计数字的行动清单/` | 仅候选；历史统计例子待审；未迁移 |
| `content/posts/2018-01-07-quickenter-new-academic-realm.md` | `/如何快速了解一个学术领域/` | `/2018-01-07-quickenter-new-academic-realm/` | 暂不创建 | 暂缓；工具、数字与媒体待核；未迁移 |

- 已迁文章：建议标题路径作为冻结地址，文件名路径在查明历史后兼容；新稿标题即使改名也不默认改 URL。百分号编码与中文路径必须当作同一路径的不同表示检查，避免双份页面或冲突。
- 未迁文章：**默认不动旧站**。若将来新站在同一主机替换旧站，必须先单独决定旧站归档与未迁路径的去向；“本轮不迁正文”绝不等于“可以删除旧路径”。
- 新主机与旧主机不同：新站 aliases 不能替旧主机做跳转；需有旧主机控制权与单独授权。域名、DNS、CNAME 与托管设置暂不操作。
- 静态 HTML 跳转不宣称 HTTP 301。若确需 HTTP 301，应先选支持它的平台规则并核查真实响应；不能先承诺 Pages 提供任意服务器规则。
- 原文指针保存在内部迁移台账；公开页只呈现获准的来源说明与历史链接，不暴露本地绝对路径、Git 内部地址或未公开材料。

## 五、取舍与验证红线

### 最小模块

建议一个“文章阅读闭环”：极简文章入口＋一篇长文页＋返回列表，长文包含标题、历史日期、整理状态、层级目录、正文与获准来源说明。归档与主题先留小入口，不预造空栏目；单篇不假装已验证相关推荐。

意向三维的**设计预期**为阅读与发现 1、可追溯 2、长期维护 1，总分 4；不是已实现的分数。实际布局、来源确认、构建与检查未完成时不得据此验收。手机/桌面任务与本人声音由负责人定标；新实践与长期积累的实际效果仍未知。

### 对本推荐最不利的三条理由

1. **来源风险**：首篇含课程转述与无一手证据的断言。反制：先确认使用边界，再独立整理、标历史口吻；核不清的部分不伪装成当前事实。若首篇授权不足，切备选而非原样搬文。
2. **维护风险**：独立布局也会产生自维护成本；Hugo 未安装，实际性能与重建未知。反制：只实现最小模板与原生配置；批准安装后再用干净重建、链接检查和阅读样本验证，不因“静态”自动判低维护。
3. **链接风险**：本地 sitemap/canonical 不足以还原线上版本；相同主机替换会损坏未迁文章链接。反制：域名与旧站处理另行决定，未明确归档与映射前不触发部署。

### 验证状态

- 初始化结构冒烟通过；三篇 URL 小实验已运行并支持“文件名不是唯一 URL”判断；候选正文哈希与原件 Git 状态未变。
- 网页组织仅经文本提取；Chrome 未连接，不宣称页面体验通过。
- 未安装或构建任一新框架，未检验 CI、部署和线上响应。
- 两路本地独立 worktree 对抗核查已完成，补强了备选统计例子的口径边界；记录见 `../reviews/003_research-boundary-review.md`。同工具体系核查不能替代跨谱系。
