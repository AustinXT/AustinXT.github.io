# 003 · 三站对照：归档、主题与合辑

> 2026-10-09；公开页面文本观察，不是视觉或阅读体验验收。本文只补充组织参考，不替代 `002_blog-direction-decision.md` 的已确认取舍。参考作者姓名为**阳志平**，前次对话误写为“杨志平”，已纠正。

## 一、谢益辉：用时间串起长期积累

观察入口：[中文日志](https://yihui.org/cn/)。

- 日志页直接按年份分组，年份与组内文章均从新到旧排列。
- 每条只用日期与文章标题作为入口；日期精确到日，同日可以有多篇，不必加摘要或图片。
- 实例：2026 年组下，2026-01-12 的[《我心似海洋》](https://yihui.org/cn/2026/01/heart-sea/)与 2026-01-11 的[《Bressanone》](https://yihui.org/cn/2026/01/bressanone/)。
- 顶部“日志”就是时间目录入口；页尾另有[搜索](https://yihui.org/search/)与 [RSS 订阅](https://yihui.org/cn/index.xml)。当前日志页文本未见分类或标签入口，不等于整个站点没有。

**借鉴价值**：让积累本身成为导航，读者可以快速扫标题、回看某年的写作。代价是时间目录不直接回答“某个主题有哪些文章”，需要独立的主题入口补足。

## 二、胡涂说：按内容形态与系列分入口

观察入口：[首页](https://hutusi.com/)。主导航包含心流、文章、合辑、关于与订阅；笔记、图谱、归档、标签、链接收在“更多”下。

| 入口 | 当前页实际结构 | 解决的问题 |
|---|---|---|
| [文章](https://hutusi.com/articles/) | 日期倒序、分页；条目有标题、简介、阅读时长、日期、类型及标签 | 阅读较完整的文章 |
| [心流](https://hutusi.com/flows/) | 按年、月分组，日期倒序；列表直接显示随笔正文，日期通向独立条目；有分页 | 浏览短记录，而非逐篇点开标题 |
| [合辑](https://hutusi.com/series/) | 系列入口带介绍与篇数；当前列出“好奇心周刊”和“年度总结” | 沿同一系列继续阅读 |
| [好奇心周刊](https://hutusi.com/series/weeklies/) | 合辑中的一个系列；按日期倒序、分页，条目有期号、日期与简介 | 按期阅读持续栏目 |

首页另分为精选文章、最新文章、近期心流和精选合辑，分别提供推荐、更新与系列入口。首页“最新文章”包含周刊条目，而本次文章列表首屏未见周刊，不能把二者视为范围完全相同的列表。

**关键区别**：分区并非一套互斥主题分类。“文章／心流”偏内容形态，“合辑”是跨篇组织，“周刊／年度总结”又是系列名称。不能把这些名称全部当作同一级标签，更不能为了导航齐全先造空栏目。

## 三、阳志平：简短首页，时间与主题并存

观察入口：[首页](https://yangzhiping.com/)与[随笔目录](https://yangzhiping.com/essays/)。既有研究见 `002_blog-direction-decision.md:35`；这里补充本次核对，不重写已确认取舍。

- 首页导航为首页、图书、随笔、简介、联系；正文提供简短身份说明、关于入口、五篇近期文章和“全部文章”入口。近期条目以日期＋标题呈现，全部文章通向随笔目录。
- 随笔目录按年份列出文章数量，当前展开 2026 年；年内文章行包含月日、标题及分类。文本提取未给出年份入口 URL，不能据此确认切换机制。
- 时间目录之外，另有“精选专栏”及[全部分类](https://yangzhiping.com/essays/categories/)，例如[阳志平谈人工智能](https://yangzhiping.com/essays/category/ai/)。
- 同页另列“精选专题”及[全部专题](https://yangzhiping.com/essays/tags/)，例如[致女儿书](https://yangzhiping.com/essays/tag/letters/)。这是页面可见的不同入口，不能据路径自行断定后台的分类规则。

**借鉴价值**：首页先让读者理解作者，再引向文章；目录则兼顾按时间回看与按主题发现。不照搬图书栏目、专题名称或个人介绍，也不因为参考站同时有分类与专题，就让本项目维护两套近似分类。

## 四、对本项目的借鉴建议（不是新增定案）

| 参考站 | 主要借鉴点 | 暂不照搬 |
|---|---|---|
| 谢益辉 | 年份分组、日期＋标题的轻量归档 | 把时间列表当作唯一找文入口 |
| 胡涂说 | 用合辑连接多篇内容，区分内容形态与系列 | 心流、周刊及全部首页分区 |
| 阳志平 | 简短身份首页，时间目录与主题入口并存 | 图书栏目与分类／专题的完整双体系 |

1. **先借谢益辉的时间底座**：全部文章采用年份分组、日期＋标题；历史日期与整理日期分开，沿用已确认取舍。
2. **借阳志平的首页与双入口思路**：首页保持简短身份说明、近期文章与全部文章入口；文章可以按时间回看，也可以从少量主题进入。初版仍只维护一套清晰主题，不新增与其重叠的分类体系。
3. **借胡涂说的系列思路，不照搬栏目数**：出现有明确顺序的连续写作后，再考虑合辑；有主题关联不自动意味着需要合辑。
4. **暂不新增心流、周刊或图书栏目**：没有相应内容与持续产出需求时，不先造空入口。

一句话：**时间归档回答“何时写过”，主题回答“写过什么”，合辑回答“接着读什么”。** 三者可以索引同一份正文，不应复制维护文章。
