description: 外部评审入口以本机接口与实际响应冒烟，不将空列表判不可用或盲猜 provider
metadata:
  type: feedback
---

**为什么**：2026-10-09 多次 OpenCode 模型/元数据查询成功退出却空输出；负责人随后指定了模型短名，但实际调用要求完整模型引用并在本地拒绝。查询空输出、CLI 存在、负责人知道入口与模型可实际调用是不同证据，重复同类查询没有推进工作。

**怎么用**：外发前先核本机版本与帮助、确认提示词文件及项目读取隔离；模型查询空输出只记“未验证”，不判服务不可用、不再重复同类探测。短名被拒绝时只从已获权限的模型标识接口补齐同一模型的 provider，不能盲猜或改模型。一次有界核查仍无证据，则按已授权候补继续或将具体缺口交人，不新增安装、收费或扩大外发材料。每次保留退出码、响应与摘要哈希；没有真实评审输出不放行。
