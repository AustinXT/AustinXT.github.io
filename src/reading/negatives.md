# 博客阅读布局 · 负例护栏

> 2026-10-09；初轮为事前攻击。三条正例硬约束对应至少九条独立负例；脚本闸能判的不能留给人判。

## 一、事后来源

负责人先提出主要板块依次速览，随后明确独立页面跳转及新菜单，联系归简介。三条原话与改前／改后指针唯一记录在 `standard.md` 的修改 1–3；旧锚点菜单不再合格。不伪造负责人选择旧编号、直接编辑文件或完整验收。

## 二、事前攻击：结构规则

以下十二项由 `../../scripts/check-reading-prototype.py` 判定，并由 `test-reading-prototype.py` 的独立破坏夹具验证。

| 编号 | 怎样毁掉它 | 应失败的规则 |
|---|---|---|
| N1 | 缺少、隐藏、错序或增加首页速览块；旧控件可重排首页 | `overview`：单一首页容器内恰有四块，顺序与标题准确；无容器外速览、旧控件或内联事件处理器 |
| N2 | 跨页复制全文，或在同一文章内追加副本 | `article`／`body`：指定八页合计只有文章详情一份正文，无容器外小节或重复连续段落，正文段落不得隐藏 |
| N3 | 外部资源、编码 SVG、自动跳转、脚本或资源穿越 | `offline`／`styles`：仅允许指定本地共享 CSS；拒绝其他加载或原生外发属性（含 ping／attributionsrc）、转义与 meta refresh |
| N4 | 同一文档两处元素同 ID | `ids`：逐文档唯一，不同页面同名 ID 合法 |
| N5 | 跨文件链接或目录指向缺失目标 | `anchors`／`files`：指定文件及片段存在；目录仍在本篇正文，加载器不沿 href 读任意文件 |
| N6 | 返回首页锚点而非独立随笔列表 | `return`：详情返回 `essays.html` |
| N7 | 首篇或简介、作品、联系入口仍首页滚动 | `recent`／`overview`／`contact`：速览进入独立文件，联系到 `about.html#contact` |
| N8 | 菜单错项、错序、错当前项，或列表不含首篇 | `navigation`／`current`／`discovery`：八页四项菜单一致；文章及分类／专题归随笔，作品预览归作品 |
| N9 | 去掉或藏起 AI 占位声明，冒充已整理文稿 | `status`：完整声明不在 hidden 祖先或 template 中；实际绘制另验 |
| N10 | 专栏／专题／时间线错序，分类超4或标签超6、目录漏关联 | `index`：按登记元数据核对顺序、去重、截取、全目录及文章指针 |
| N11 | 补造空年、漏掉非空年、索引日期与标题另起一份 | `metadata`／`timeline`／`index`：从详情唯一元数据派生全部非空年、标题与日期，非法数组或日期不默跳 |
| N12 | 样本当成真实作品、图标缺失或详情无法返回 | `works`：真实区未登记就为空，排版行与详情明确非实际，原生详情与返回入口齐全 |

## 三、字面闸

`check.sh` 复用通用执行器：按扩展正则检查；命中退 1，空模式、坏正则或不可读文件退 2。结构规则另跑，字面通过不等于 HTML 或阅读体验通过。

```PATTERNS
@import[[:space:]]|https?://|src=["']//	不加载远程资源；结构检查补协议与属性核对
/Users/|vault/raw/|file://	页面不泄露本地原件或个人路径
已发布|已人审|定标通过	AI 候选不得声称发布或人验收
```

## 四、人核对：机器不能代判

```CHECKLIST
首页是否确实提供四个板块的简短速览，而不是四个空标题或完整正文堆叠
实际点击菜单是否改变文档地址，联系是否到简介页，手机与桌面排版和键盘操作是否可用
候选简介是否符合本人意向，占位文章是否被误解成正式正文
```

## 五、盘点与边界

正例硬约束 3 条，独立结构负例 12 条，负例／正例为 4；额外字面闸与人工核对不重复计数凑比例。事后数据负例当前为 0。

结构、字面和反例测试只验证规则；浏览器行为、文稿语义、版权、本人声音、真实构建与上线仍须各自验证。不得为让样本通过而删除失败夹具或放宽人的合格线。
