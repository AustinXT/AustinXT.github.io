# 智能时代蛮子 · 博客 · 意向书

> 2026-10-09 初稿；负责人于同日明确回复「符合，请继续」，已确认收敛方向并授权继续有界研究。技术取舍、方法评审、制作与发布仍分别放行。

## 收敛方向（唯一）

建设「智能时代蛮子」的长期个人博客，让重新整理的本人文章与持续的新实践，以简洁、可检索、可追溯的方式被阅读和积累。

## 每件产出与方向的关联度

每个网站模块或待迁移文章按三项评为 0–2 分：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 阅读与发现 | 无法阅读或找到 | 可读且有入口 | 手机与桌面可读，目录或搜索能支持明确的阅读任务 |
| 内容可追溯 | 无出处、冒充新实践 | 有原文与日期指针 | 能区分历史事实、新增解释和已过时结论，并保留原文关联 |
| 长期维护 | 需重复维护正文或依赖不可复现 | 单一正文源、配置明确 | 从干净环境可重建，链接与内容规则可检查 |

初版合格线为总分至少 4 分、每项不为 0；规则通过不替代负责人定标、事实、版权和隐私审核。实际任务与样本由 proto 阶段的人来确定。

## 真难题

长期难题候选：将跨年份、跨主题的个人写作积累成读者能持续找到和理解的知识结构，并在持续迁移与更新时保住出处、链接和本人声音。

目前没有证据证明这一难题已经历多年反复投入；research 会核实。换主题、搬目录和挑框架本身不是长期难题。

## 不做什么

| 不做 | 为什么不做 |
|---|---|
| 初始化时直接做首页、批量迁文或决定框架 | 先定方向和方法，再据材料选型与定标 |
| 把旧博客完整变成新站，或默认所有旧文都迁移 | 用户要求的是部分内容重新整理，不是全量镜像 |
| 修改、删减旧博客参考原件 | 原文与 Git 历史是核验和重新整理的依据 |
| 照搬 `yangzhiping.com` 的文章、代码或设计资产 | 它是阅读与组织方式的参考，不是复制授权 |
| 把旧薪酬、版本、统计或经历当成当前事实 | 历史实践有时间边界，新增解释不能伪装成原文 |
| 未获授权的安装、外发、上线、域名切换或提交推送 | 涉及机器、内容、声誉与历史链接的决定权属于负责人 |
| 承担所有平台的营销选题与运营 | 品牌与多渠道协同属于上游项目；交接身份见 `meta.md` |

## 真相源与权重

1. 负责人明确指令及本人认可的改稿、定标样本；本次指令与移动证据见 `../docs/research/001_reference-source.md`。
2. 自有旧博客原件及其 Git 历史；位置和身份唯一登记在 `meta.md`，旧文只能证明当时写过什么，不自动证明当前有效。
3. 可核验的一手技术资料及实际构建、阅读任务、链接测试证据；AI 推断、参考站视觉印象不是事实证据。

旧实践是事实来源，不是新站标准；新标准由负责人定标，AI 不代为认定。

## 作品区与验证闭环

- 作品区为 `src/`；单位为可独立验收的网站模块或包，实体语义见 `cog.md`。文章是网站内容输入，不是新的多平台投放批次。
- 一件成品包括模块实现或已整理正文、来源与迁移记录、规则检查以及负责人验收；模块具体路径采用选定生态的原生约定，当前没有模块子目录。
- 规则验证：初始化结构、清单与原件忽略保护；框架确定后追加实际构建、内容元数据、内部链接及旧 URL 映射检查。
- 判据验证：AI 按上述关联度以及 `../specs/` 的人审样本检查阅读、出处和维护成本；旧文迁移先做一篇，而不是先批量。
- 实效验证：负责人用手机与桌面完成首页到文章、找到某主题、继续阅读等任务，确认本人声音与整理边界，再决定扩大迁移；没有观察到的效果标为未验证。
- 人审通过、允许制作、允许公开发布是三个不同状态；任何一个都不自动推导另外两个。
