# 智能时代蛮子 · 博客 · 现实约束

## 已知现实

- 用户要求另起独立博客工程，旧博客作为参考源，未来只有部分内容重新整理进入新博客。
- 用户随后明确纠正「不是拷贝，是移动」；完整移动已经执行，记录见 `../docs/research/001_reference-source.md`。
- 本地环境为 macOS；旧博客移动前约 199 MB，磁盘约 521 GiB 可用。旧仓库 Git 历史、未提交修改和未跟踪文件均保留。
- 旧博客的历史技术识别是 Hugo / FixIt；新框架、主题与部署方式尚未确定，旧栈不自动成为新栈。
- 参照网站已由用户提供；本轮尚未核查在线站点，不把它的实际导航、样式或技术栈写成已知事实。

## 授权与隐私现实

- 本轮明确授权新项目初始化和旧博客整目录移动；未授权修改或删减参考原件、安装、对外送审、付费、发布、提交或推送。
- 自有旧博客仍是独立 Git 仓库，整个目录被新仓库忽略；忽略规则不是异地备份。
- 旧仓库原有 remote 不自动成为本项目 remote；未提交文件不因保留旧 `.git` 就获得远程备份。
- 未公开文章、凭据、个人数据与第三方素材的使用和外发权限尚未核实；本轮没有读取凭据、`tmp/` 正文或个人数据。
- 本地 Git 尚无提交或远端，新初始化文件和被忽略资料目前没有已验证的异地副本。
- 上游品牌项目已有的外发、模型配置或 Git 授权不自动延伸到本项目。
