## 作品单位

作品单位是**可独立验收的网站模块或包**，主干持续演化；文章按框架原生内容约定组织，不用日期投放目录伪装网站模块。

当前 `src/` 直接作为 Next 原生工程根目录，原八页 HTML 原型已归档至 `_archive/20261016-reading-delisted/`，仅供布局标准追溯与独立原型回归。框架源码子目录逐项登记；依赖与构建产物按 Git 忽略规则排除。技术修订正本见 `../docs/research/002_blog-direction-decision.md`，正文状态见迁移台账。

## 参与者

| 参与者 | 负责 | 不负责 |
|---|---|---|
| 负责人 | 方向、内容取舍、声音与阅读样本定标、上线授权 | 不必手工判可自动化的规则 |
| AI | 来源索引、有界比较、草案、实现和本地检查 | 不改原件、不虚构事实、不自动上线 |
| 读者 | 提供实际阅读与发现反馈 | 不替代事实、版权与隐私核验 |

## 关键关系

- 原件与历史只证明已有事实，不决定新站标准；重新整理的正文以原文为证据，且注明新增解释。
- 上游品牌项目提供品牌与内容意向，本项目提供可阅读的博客工程；两边不复制维护同一成品正文。
- 本项目 root `.git` 与原件内的 `.git` 相互独立；原件不作为子模块或新站构建输入。
- 身份、位置及参考网址唯一登记于 `meta.md`；方向只在 `intent.md`。
- 四步构成循环；研究可以提出意向修订，但不替负责人拍板。
